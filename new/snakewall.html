Overview

The game

SnakeWall puts a playable game of Snake on your Android home screen. Set it as your wallpaper, tap start, and steer with four on-screen buttons while your app icons sit on top.

It began as an attempt to copy the Snake widget on Nothing phones, became a wallpaper when widgets turned out to be the wrong tool, and went from first commit to a working release in six days. It has been on Google Play since January 2025, and is now at v1.0.8.

Systems

How it works

01

A game inside the wallpaper service

There is no activity running the game. Everything lives in a WallpaperService.Engine: a game thread moves the snake and draws each frame to the wallpaper's surface with the Canvas API, and touches arrive through the wallpaper's own touch callback.

02

The board

A 19 × 19 grid sized to the screen width. The snake is a linked list of grid coordinates: each step adds a head and removes the tail, and the walls wrap around to the opposite side.

03

Speed

The game starts at one step every 200 ms. Every third piece of food shortens the step, in smaller amounts as it gets faster, so it ramps quickly at first and then levels out.

04

Being a good wallpaper

A wallpaper must not drain the battery. The game pauses itself when the screen turns off, when the home screen is covered, and after ten seconds without input. The thread sleeps between steps, so nothing redraws faster than the snake moves.

05

Customisation

Five colour themes, an option to change colours automatically, a grid toggle, a vibration toggle, and a custom image as the background with light or dark controls. A preview in the app renders the same game view before you apply it.

06

Releases

GitHub Actions builds debug and signed release APKs. The best score is kept in shared preferences, and the app collects no data.

The hard part

From widget to wallpaper

The first plan was a home-screen widget like Nothing's. I wrote a custom view for the game with swipe gestures, then hit the wall: Android widgets cannot run a custom view or a game loop.

I posted about being stuck on my Telegram channel, and someone suggested a live wallpaper instead. A wallpaper gets a real drawing surface and its own touch events, which is everything the game needed.

One limit remained. A swipe on the home screen belongs to the launcher: it opens the app drawer or the notification shade. So the game uses four on-screen buttons, and that constraint ended up defining how it looks.
